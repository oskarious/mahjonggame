The `.chip` class: a small pill that states a fact — a name, a status, a limit.

Source: `apps/web/src/app.css`.

- Neutral (`panel-2`): the account chip, labels.
- `.good` (`ok` / `ok-ink`): positive state (Tenpai).
- `.bad` (`danger` / `danger-ink`): Furiten, "liable".
- `.gold` (`accent` / `accent-ink`): Riichi, limit hands (Mangan).

Always a word, never colour alone. `chip` type style, `radius-pill`, 3px × 9px padding.
